Boîte à outils pour les commandes de pilotage sur Fly Simulator.
Version 1.0.0

Comment intégrer les commandes :
Ajouter la librérie à la solution.
Ajouter la librérie aux références du projet executable.
Dans le program.cs ajouter :
	using commandes.Interfaces;
	using controls.Wrapper;
Intégrer le package SimConnect.

Instancier les commandes :
	Icommandes controls = new SimConnectControls(client);

Commandes possibles :

Bouger l'aileron :
	await controls.SetAileron("valeur");
Changer l'elevateur :
	await controls.SetElevator("valeur");
Changer le rudder :
	await controls.SetRudder("valeur");
Changer l'autopilotheading :
	await controls.SetAutopilotHeading("valeur");

Les valeurs peuvent être négatives ou positives suivant le sens de mouvement désiré.


Fonctionnement :

Le programme executable utilise le registre de fonctions présent dans Icommande.cs, ces fonctions sont construites dans commande.cs.

Une commandes est donc créée => référée pour être disponible => utilisable dans un executable.


Il est bien sûr important de connecter le programme executable au simulateur comme tout projet utilisant SimConnect.

Le simulateur doit déjà être lancé à l'execution du programme sinon quoi le programme rencontrera une erreur.
